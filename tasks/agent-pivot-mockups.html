TailorList Agent

Pasar de "un dashboard de playlists con un clustering muy laborioso" a "un curador al que le pedís lo que querés escuchar". Los dashboards se quedan, pero como vistas que el agente abre y explica.

Mi opinión

Sí, tiene sentido, y el refactor en curso es justamente lo que lo hace barato. Si core/ queda como funciones puras DataFrame→DataFrame sin Streamlit, cada una se convierte en una tool casi gratis.

  • LangGraph encaja, pero solo para el flujo de curaduría: tiene estado, loops ("cambiá esto"), una aprobación humana antes de exportar (interrupt) y sesiones que hay que poder retomar (checkpointer). Eso es exactamente lo que hoy te cuesta en 6_My_Clusters.py con sids, cookies y progreso en MySQL.
  • Para preguntas analíticas no hace falta un grafo. Un loop de tool use alcanza. No armaría una arquitectura multi-agente con supervisor: es complejidad sin ganancia para este tamaño.
  • El dolor real que resuelve es la asignación manual de clusters y los ~39 temas sin familia de género. Eso es trabajo de LLM: clasificar con criterio y pedir confirmación.

El grafo

Un router barato decide si es pregunta o pedido de curaduría. El subgrafo analista es un loop de tools. El curador es donde LangGraph se gana el lugar: estado tipado (filtros, candidatos, propuesta), el loop de ajustes y la pausa antes de cualquier efecto externo.

Tu refactor es la capa de tools

De core/ a tools

No hay que frenar el refactor. Al contrario: conviene sumarle una regla, que cada función de core/ tenga firma tipada, docstring clara y devuelva algo serializable. Esas tres cosas son lo que el LLM ve.

Antes de comprometerse

Riesgos

Costo

LLM en una demo pública

Hoy la app está offline y era gratis de correr. Con agente, cada visitante cuesta tokens. Opciones: límite por visitor_id, modelo chico para router y analista, o "traé tu API key".

Datos

Audio features de Spotify

El endpoint está deprecado y dependés de tu fallback DB; 86 de 450 temas no tienen features. El agente tiene que decirlo en cada respuesta, como en los mockups, o va a inventar.

UI

Streamlit y chat

st.chat_message y streaming andan para un MVP, pero el rerun completo y los interrupts con botones se pelean. Si el agente crece, el front de chat probablemente se va de Streamlit y los dashboards quedan.

Persistencia

Checkpointer y MySQL

LangGraph trae checkpointers oficiales para SQLite y Postgres, no para MySQL. Para empezar alcanza SQLite; si vuelve a la nube, Postgres es más simple que mantener uno propio.
